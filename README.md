# وضعیت پول — شبیه‌ساز ثروت و سود مرکب

شبیه‌ساز تعاملی رشد سرمایه با سود مرکب، ساخته‌شده با React + Vite + Recharts.
داده تورم واقعی ایران (۲۰۱۱ تا ۲۰۲۵) داخلش هست، نه یک عدد فرضی ثابت.

## فیچرها

- محاسبه دقیق سود مرکب ماهانه (نه تقریبی)
- نمودار «روبان رشد»: تفکیک اصل پول از سود کسب‌شده
- ۴ حالت فرض تورم: دستی / میانگین تاریخی ایران / خوش‌بینانه / بدبینانه (بر پایه داده واقعی)
- بک‌تست تاریخی: با تورم واقعیِ رخ‌داده در هر سال، ببین اگه از یه سال خاص شروع می‌کردی الان کجا بودی
- مقایسه با ۴ طبقه دارایی رایج (بانک، طلا، بورس، دلار) با نرخ قابل‌ویرایش
- شبیه‌سازی مونت‌کارلو برای نمایش عدم قطعیت بازار (بازه ۸۰٪ احتمال)
- محاسبه معکوس هدف مالی
- جدول سال‌به‌سال + خروجی CSV
- سال‌های شمسی، تبدیل ارقام فارسی/انگلیسی
- پوسته روشن/تیره
- اشتراک‌گذاری با لینک (تنظیمات داخل URL ذخیره می‌شن)
- نسخه چاپ/PDF گزارش

## اجرای محلی

```bash
npm install
npm run dev
```

## دیپلوی روی Vercel

**روش ۱ — از طریق GitHub (پیشنهادی):**
1. یه ریپازیتوری جدید توی GitHub بساز و این پوشه رو push کن:
   ```bash
   git init
   git add .
   git commit -m "اولین نسخه"
   git branch -M main
   git remote add origin <لینک-ریپازیتوری-شما>
   git push -u origin main
   ```
2. برو به [vercel.com](https://vercel.com) → **Add New Project** → ریپازیتوری رو انتخاب کن.
3. Vercel به‌صورت خودکار فریم‌ورک Vite رو تشخیص می‌ده (Build Command: `vite build`, Output: `dist`). فقط دکمه **Deploy** رو بزن.

**روش ۲ — از طریق Vercel CLI (سریع‌تر، بدون GitHub):**
```bash
npm install -g vercel
vercel
```
دستورات رو دنبال کن؛ در چند ثانیه یه لینک زنده می‌گیری.

## ساختار پروژه

```
src/
  data/inflationHistory.js   داده واقعی تورم ایران + توابع میانگین/بهترین/بدترین سال‌ها
  utils/jalali.js            تبدیل میلادی↔شمسی، فرمت اعداد فارسی
  utils/finance.js           فرمول‌های مالی: سود مرکب، مونت‌کارلو، بک‌تست، محاسبه معکوس
  components/                کامپوننت‌های رابط کاربری
  App.jsx                    ترکیب همه‌چیز + مدیریت state
```

## نکته مهم

داده‌های تورم تاریخی تقریبی و برای مقاصد آموزشی/نمایشی جمع‌آوری شده‌اند (منبع: بانک جهانی، IMF، Macrotrends). برای گزارش رسمی حتماً با آمار بانک مرکزی یا مرکز آمار ایران تطبیق بده. این ابزار توصیه سرمایه‌گذاری نیست.
